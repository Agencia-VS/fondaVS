# FondaVS 2.5D stage

The current implementation is a procedural Canvas renderer in `src/components/stage/scene25d.ts`. It is intentionally the first, lightweight delivery: it gives the host a fixed-camera depth composition while keeping the existing 2D rules, CPU mode, Supabase transport and Vercel deployment unchanged.

The JSON contracts in this folder describe a later Blender-baked asset path. They are pending explicit visual approval. Do not call Meshy or spend credits from this package.
